# Atlas X

Site one page de l'agence **Atlas X** : web, IA et automatisation pour artisans, TPE et PME.

Les offres forment le système **ASTRA** : Apogée (sites vitrines), Signal (SEO, GEO, SEA, SMA), Talos (agents IA), Relais (automatisations), Astrolabe (modules sur mesure).

Site statique (HTML, CSS, JS), sans build, publié avec GitHub Pages : https://meta-h777.github.io/atlas-x/
